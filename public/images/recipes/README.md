# Recipe images

The bundled recipe fixture contained S3 URLs signed in July 2024 with one-hour expirations. These are replaced with local assets so no credentials or external image host are needed at runtime.

Photos recovered from the original publishers are listed below. Recipes whose original photos could not be recovered use `pizza-fallback.jpg`, an illustrative pizza photo (the Pizza Margherita image), not a photograph of that specific recipe. The shared image component also uses this fallback for missing or failed images. Recipe text and layout are unchanged.
